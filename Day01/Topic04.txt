⭐ Working with oc CLI and the Web Console in OpenShift
OpenShift provides two primary interfaces for interacting with the platform:

Web Console — visual, user-friendly, great for developers and beginners

oc CLI — powerful command-line tool for automation, scripting, and advanced operations

Both interfaces talk to the same OpenShift API, but each is suited for different tasks.

🖥️ 1. OpenShift Web Console — Visual, Developer-Friendly Interface
The Web Console is designed for ease of use, especially for developers, testers, and workshop attendees.

🧰 2. oc CLI — Powerful, Scriptable, Automation-Friendly
The oc CLI is the command-line interface for OpenShift.
It extends kubectl with OpenShift-specific capabilities.

🎯 Why oc CLI is important
Automation

CI/CD pipelines

Scripting

Troubleshooting

Bulk operations

Access to advanced features not exposed in the UI

🔐 Logging In
Code
oc login <cluster-url>
📁 Working with Projects
Code
oc new-project demo
oc project demo
oc get projects
🚀 Deploying Applications
Using S2I:
Code
oc new-app https://github.com/sclorg/nodejs-ex.git
Using an image:
Code
oc new-app quay.io/openshiftlabs/workshop-dashboard
🔗 Exposing Services
Code
oc expose svc/workshop-dashboard
oc get routes
📦 Inspecting Resources
Code
oc get pods
oc get svc
oc get dc
oc get is
oc get bc
🔍 Troubleshooting
Code
oc logs <pod-name>
oc describe pod <pod-name>
oc get events --sort-by=.metadata.creationTimestamp
🛠️ Editing Resources
Code
oc edit dc/myapp
oc edit bc/myapp
📜 Applying YAML
Code
oc apply -f deployment.yaml

Trainer explanation
The Web Console is great for learning and visualizing.

🧠 4. Typical Workflow for Workshop Attendees
Step 1: Log in to Web Console
Explore Developer Perspective → Topology → Builds → Monitoring.

Step 2: Log in using oc CLI
Code
oc login <sandbox-url>
Step 3: Create a Project
Code
oc new-project day1-lab
Step 4: Deploy an App
Code
oc new-app quay.io/openshiftlabs/workshop-dashboard
Step 5: Expose It
Code
oc expose svc/workshop-dashboard
Step 6: View It in Web Console
Topology → Click the node → Open Route URL.

This dual approach helps attendees understand both visual and command-line workflows.

🎯 Trainer’s Closing Line
The Web Console helps you see OpenShift.
The oc CLI helps you control OpenShift.
Mastering both gives you the full power of the platform.
